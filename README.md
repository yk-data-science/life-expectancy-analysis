# life-expectancy-analysis
This project analyses global life expectancy data by region and gender, covering data from 2000 to the present. The aim is to explore trends and compare differences between regions and genders. Python libraries like Pandas, Seaborn, and Matplotlib will be used for data manipulation and visualisation.
