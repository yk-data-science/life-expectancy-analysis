# life-expectancy-analysis
This project analyses global life expectancy data from 2019 to 2024 using UN DATA, focusing on trends before, during, and after the COVID-19 pandemic. The aim is to explore how regions and gender differences influence life expectancy. Python libraries like Pandas, Seaborn, and Matplotlib will be used for data manipulation and visualisation.


# README

## Dataset Breakdown
- **2019 data**: Pre-COVID period
- **2020 to 2023 data**: COVID period
- **2024 data**: Post-COVID period
